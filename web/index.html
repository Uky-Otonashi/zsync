🚀 首次接入 —— 在本机启动客户端 agent

本页面由中央服务器提供, 读取本机 zcode 项目需要在本机运行一个轻量 agent(纯 Python 标准库, 无需安装任何依赖):

  1. 下载工具包:
  2. 解压到任意目录(如 C:\zsync)
  3. 双击 start-agent.cmd(Windows)或运行 python zsync.py serve --agent(Linux/macOS)
  4. 回到本页点击「重新检测」, 首次将引导确认本机 zcode 目录(默认 ~/.zcode 自动探测), 之后自动加载本机项目清单

提示: agent 只监听 127.0.0.1:8643, 不对局域网开放。浏览器若弹出"允许访问本地网络"请选择允许。开机自启: 把 start-agent.cmd 的快捷方式放入 shell:startup。
